FuriGram

FuriGram — модифицированный Android-клиент Telegram на основе AyuGram4A.

Планируемые возможности

- Собственный дизайн и иконка приложения.
- Дополнительные настройки приватности.
- История сообщений и фильтры.
- FuriGram Visual Premium — локальные визуальные эффекты и оформление.
- Дополнительные темы и анимации.
- Уникальные функции FuriGram.

Благодарности

Проект основан на AyuGram4A и использует исходный код его авторов. Благодарности всем разработчикам оригинального проекта и его предшественников.

FuriGram — независимый проект, не являющийся официальным приложением Telegram.
